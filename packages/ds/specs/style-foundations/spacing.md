# Spacing

Our spacing system.

## Spacing Guidelines

This design system uses an 8 pixel grid system for page layouts and spacing between text elements and components. The system is sometimes expressed in `rem` units for improved flexibility and accessibility. For reference, `1rem` defaults to `16px`.

Use these spacing recommendations when designing app screens or content pages.

## Spacing Reference Tokens

The spacing token palette is used as the reference for areas of the system that require spacing.

## Semantic Spacing

Standard semantic spacing patterns map common layout and content needs to reference spacing tokens.

| Token                                        | Value | Reference      |
| -------------------------------------------- | ----: | -------------- |
| `lightmode.-content.paragraph.marginBottom`  |  24px | `ref.space.07` |
| `lightmode.card.marginBottom`                |  24px | `ref.space.07` |
| `lightmode.-content.heading.marginBottom`    |  32px | `ref.space.08` |
| `lightmode.-content.subheading.marginBottom` |  32px | `ref.space.08` |
| `lightmode.-layout.section.marginBottom`     |  48px | `ref.space.11` |
| `lightmode.table.marginBottom`               |  48px | `ref.space.11` |
