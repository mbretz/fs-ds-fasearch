# LinkHelp

A Help Link directs users to documentation for novice assistance, usually presented as a question and paired with a circled question mark icon.

## Guidelines

- Use descriptive link language, such as "Learn more," "What's this," "Explain this," "Tell me more," or a question phrased in the user's language.
- Link to help content from text when a sentence on the screen needs supporting documentation.
- Do not pair help links with tooltips.
- Avoid using the word "Help" as the link text.

## Accessibility

### Keyboard controls

| Key   | Behavior                        |
| ----- | ------------------------------- |
| Tab   | Moves focus to the link.        |
| Enter | Activates the focused link.     |
| Tab   | Moves focus away from the link. |

### Focus management

A link should take the user to a new page or location. If sending the user to a specific location on a page, place focus where it helps them get oriented, such as the main heading for that section.

### Screen reader behavior

On focus, announce the visible link text, any visually hidden text, and the role. The question mark icon should not announce.

Example: "Learn more about life insurance, visited link."
