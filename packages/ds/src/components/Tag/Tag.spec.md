# Tag

Tags categorize and label items using keywords for organization and description.

## Guidelines

Tagging lets users categorize content through relevant keywords associated with a piece of information. Tags are helpful when content maps to multiple categories and are typically used in groups.

- Use tags in moderation, especially when combined with other visuals.
- Avoid word wrapping within tags.
- Keep tag text concise and keyword-like; avoid phrases.

## Variants

- Compact

## Accessibility

Use the visible text of the tag to indicate the category grouping rather than relying only on color.

### Keyboard controls

None.

### Focus management

None.

### Screen reader behavior

Announce the visible text.
